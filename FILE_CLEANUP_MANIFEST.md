**Version:** 1.0.0 (Phase 1.5 Specification)  
**Governance Policy:** STRICT PRE-CLEANUP VERIFICATION PROTOCOL. No files are deleted or moved until each verification gate is passed.  
**Database Clause:** ZERO DATABASE OBJECTS TOUCHED. PostgreSQL tables, sequences, indexes, and migrations are strictly excluded from Phase 2.

## 1. Governance Verification Protocol

Before any file or directory in this manifest is deleted or moved, the following 5-point verification protocol must be executed:

```text
CANDIDATE ITEM
      │
      ├─► 1. Check .gitignore entry (ensure generated files are ignored)
      ├─► 2. Check Git tracking status (git ls-files --error-unmatch)
      ├─► 3. Check code references / imports (grep across all source files)
      ├─► 4. Verify build reproducibility (can npm/gradle re-create this?)
      │
      ▼
  EXECUTE ACTION (Safe Delete OR Move to _archive/)
      │
      ▼
  POST-ACTION BUILD VERIFICATION
      ├─► npm run build (Web / Admin)
      ├─► customer-app build test
      └─► Automated test runner execution
```
